# 일정 투표

워크스페이스의 ‘일정 투표’에서 생성합니다. 예상 인원은 주최자를 제외한 수입니다.
주최자의 일정·이동시간과 겹치지 않는 후보를 1~200개 정하고 링크를 공유합니다.
참석자는 로그인 없이 이름·이메일과 가능한 시간을 복수 선택합니다. 가능한 시간이 없다는 응답도 가능합니다.
같은 이메일의 중복 응답은 막으며, 처음 응답한 브라우저나 본인 전용 수정 링크로 응답을 수정합니다.
전용 링크는 다른 사람에게 공유하면 안 됩니다. 주최자만 응답자 연락처와 전체 응답을 봅니다.

최소 예상 인원 이상이 응답했고 모든 응답자가 선택한 후보만 확정할 수 있습니다.
응답자 신원을 이메일 인증하는 기능은 아니므로 주최자가 참석자 목록을 확인해야 합니다.
공통 시간이 없으면 후보를 추가해 다시 응답받습니다. 기존 후보와 응답은 보존됩니다.
후보는 예약을 점유하지 않습니다. 확정 직전 Google 일정을 다시 조회하고 DB 트랜잭션으로 다른 예약과 충돌을 확인합니다.
확정 후 예약 목록에 한 건을 생성하고 주최자 Google 캘린더에 등록합니다. 확정·취소 메일은 참석자별로 발송됩니다.
참석자가 전체 모임을 취소할 수 없도록 개인 예약 관리 링크는 메일에 넣지 않습니다.
확정 모임 취소는 주최자가 수행합니다. 일정 변경이 필요하면 취소 후 새 투표를 만듭니다.

적용 마이그레이션: `supabase/migrations/202609300002_polls.sql`.
기존 알림 큐·재시도·리마인더·캘린더 재시도 처리에 연결됩니다. 알림 off/dry-run 정책을 그대로 따릅니다.
정원이 있는 설명회형 그룹 예약은 별도 기능이며 이번 일정 투표에 포함되지 않습니다.
