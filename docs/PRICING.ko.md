요금과 한도의 기준값은 `lib/plans.ts` 하나에서 관리합니다. 랜딩 페이지 요금표도 이 파일을 읽어 표시합니다.

### 근거 (타 서비스 비교)
- **Calendly**: 무료는 이벤트 유형 1개·캘린더 1개·리마인더 없음·브랜딩 표시. Standard는 월 $12(연간 $10). 유형 무제한, 브랜딩 제거, 리마인더·워크플로 제공.
- **Cal.com**: 개인 무료 플랜이 넓고, 유료는 사용자당 월 $15부터.
- **SavvyCal**: 무료 플랜 없이 월 $12부터. **TidyCal**: 무료 + $29 평생 라이선스.
- 공통 패턴은 "무료 = 링크 1개로 충분히 써보기, 유료 = 여러 개 + 리마인더 + 브랜딩 제거"입니다. 노쇼를 줄이는 **리마인더**와 **예약 페이지 무제한**이 가장 흔한 업그레이드 이유라서, 이 둘을 프로의 핵심으로 둡니다.
- 프로 월 5,000원은 Calendly Standard(약 16,000원)의 1/3 수준입니다. "부담 없는 개인 구독"으로 포지셔닝합니다.
- **예약 횟수는 두 플랜 모두 무제한**으로 둡니다. 예약이 많아질수록 주최자가 리마인더·규칙을 원하게 되어 자연스럽게 업그레이드로 이어집니다.

## 2. 무료 체험·결제·해지
- **14일 무료 체험**: 카드 등록 없이 프로 기능 전체를 씁니다. 끝나면 자동으로 무료 플랜으로 돌아가며 자동 결제되지 않습니다.
- **결제 방식**: 월간 또는 연간 정기결제(카드). 결제대행은 토스페이먼츠 빌링(자동결제)을 권장합니다.
- **해지**: 언제든 설정에서 해지할 수 있습니다. 해지해도 이미 결제한 기간이 끝날 때까지 프로를 계속 씁니다.
- **환불**(전자상거래법 기준)
  - 결제 후 **7일 이내**이고 프로 기능을 쓰지 않았다면 전액 환불합니다.
  - 그 밖에는 월간은 환불하지 않고 다음 결제부터 중단합니다. 연간은 사용한 개월 수를 월간 요금(5,000원)으로 계산해 빼고 남은 금액을 환불합니다.
- **다운그레이드**: 무료로 바뀌면 활성 예약 페이지가 1개만 남습니다. 가장 최근에 수정한 페이지 1개는 유지하고 나머지는 **비활성(삭제 아님)**으로 바꿉니다. 이미 확정된 예약과 캘린더 일정은 그대로 둡니다.
- **가격 변경**: 인상 시 30일 전에 이메일로 알립니다. 기존 구독자는 다음 갱신일부터 적용합니다.

## 3. 출시 전 · 기존 사용자
- 결제 기능이 열리기 전까지는 **모든 사용자가 프로 기능을 무료로 씁니다**(베타). 랜딩에도 그렇게 표시합니다.
- 결제를 열 때 기존 가입자에게는 안내 메일을 보내고, 14일 체험을 그 시점부터 새로 시작합니다.

## 4. 결제 출시 전에 할 일
1. **플랜 저장**: `moa_subscriptions`(owner_id, plan, status, current_period_end, billing_key 등) 테이블과 RLS
2. **한도 적용**: 예약 페이지·투표 활성화 시 플랜 한도 검사(DB 트리거로 강제), 리마인더·예약 규칙·이동 시간은 프로만 동작
3. **결제 연동**: 토스페이먼츠 빌링키 발급 → 정기결제 → 웹훅으로 상태 갱신, 영수증 이메일
4. **설정 화면**: 현재 플랜, 다음 결제일, 결제수단 변경, 해지·환불 요청
5. **약관 개정**: 이용약관에 유료 서비스·결제·해지·환불 조항을 추가하고, 개인정보처리방침에 결제대행사(토스페이먼츠) 위탁을 추가
6. **통신판매업 표시**: 이미 랜딩·약관 하단에 표시 중(2024-서울마포-2126)
